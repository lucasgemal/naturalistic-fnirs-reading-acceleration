## Overview

This repository contains the full analysis pipeline for an fNIRS study investigating the neural
mechanisms underlying reading acceleration in 3rd and 4th grade children (ages 8–9) trained with
the ACELETRA® software. The study employs a randomized longitudinal design (10 sessions over 3 weeks)
with portable fNIRS recorded in a naturalistic classroom setting.

**Main hypotheses:**
1. ACELETRA® training accelerates the automatization of neural reading mechanisms (reduced HbO over sessions = neural efficiency gain).
2. Training increases functional connectivity between left temporal and left frontal cortex.

### `scripts/`

#### MATLAB — fNIRS Preprocessing and GLM (NIRS Toolbox)

| Script | Description |
|---|---|
| `contagem_nova.m` | Reconstruct task-block stimuli from trial-level ACELETRA triggers |
| `pre_processamento.m` | Full preprocessing pipeline + first-level GLM (SubjStats) |
| `MixedEffects.m` | Second-level group GLM: `beta ~ -1 + group:experiment + (1\|subject)` |
| `conectividade_funcional.m` | Functional connectivity (AR correlation) + export to Excel |
| `relatorio_geral.m` | Quality control report for preprocessed data and GLM outputs |

#### Python — Statistical Models and Visualizations (Jupyter Notebooks)

| Notebook | Description |
|---|---|
| `fnirs_neural_efficiency.ipynb` | Compute Neural Efficiency index: NE = (−z_VELmed − z_beta) / √2 |
| `lmm_neural_efficiency.ipynb` | LMM: `NE ~ group × session + VELmed_baseline + (1\|subject)` per ROI |
| `individual_ne_regressions.ipynb` | Individual OLS slopes of NE; Fisher exact + t-test between groups |
| `beta_activation_lmm.ipynb` | LMM: `beta ~ group × session + roi + (1\|subject)` |
| `connectivity_lmm_raincloud.ipynb` | LMM: `connectivity ~ group × session + conn_baseline + (1\|subject)` |
| `channel_lmm_anatomical.ipynb` | Channel-level LMM with FDR correction; anatomical labelling |
| `corr_hbo_velmed.ipynb` | Spearman: HbO slope × reading-time slope per FDR-significant channel |
| `ne_mannwhitney_raincloud.ipynb` | Mann-Whitney U + raincloud visualization |
| `ne_trajectory_plot.ipynb` | Trajectory plot: mean NE ± SEM per group and ROI |
| `lmm_roi_interaction.ipynb` | Three-way LMM: group × session × ROI interaction |
| `Calculo_eficiencia.ipynb` | Early draft (see `fnirs_neural_efficiency.ipynb` for canonical version) |

### `results/`

Excel tables and PNG figures generated by the analysis scripts.

| File | Content |
|---|---|
| `fnirs_neural_efficiency.xlsx` | NE index: 252 rows (14 subjects × 9 sessions × 2 ROIs) |
| `lmm_results_by_roi.xlsx` | LMM coefficients for NE (frontal and temporal) |
| `beta_lmm_hbo.xlsx` / `beta_lmm_StO2.xlsx` | Beta activation LMM results (HbO primary, StO2 supplementary) |
| `channel_lmm_hbo.xlsx` | Channel-level LMM: 15 channels, FDR-corrected (6 significant, q < 0.05) |
| `connectivity_results_hbo.xlsx` | Inter-regional connectivity LMM results |
| `individual_ne_slopes.xlsx` | Individual OLS slopes of NE per subject × ROI |

Manuscript drafts and methods/results sections in `.docx` format.

## Analysis Pipeline — Recommended Execution Order

```
1. contagem_nova.m            # Reconstruct stimulus events
2. pre_processamento.m        # fNIRS preprocessing + GLM → SubjStats.mat
3. MixedEffects.m             # Group-level GLM → GroupStats.mat
4. conectividade_funcional.m  # Connectivity → connstats_completo.xlsx

5. fnirs_neural_efficiency.ipynb    # Compute NE index
6. lmm_neural_efficiency.ipynb      # LMM on NE by ROI
7. individual_ne_regressions.ipynb  # Individual NE slopes
8. beta_activation_lmm.ipynb        # Beta activation LMM
9. connectivity_lmm_raincloud.ipynb # Connectivity LMM
10. channel_lmm_anatomical.ipynb    # Channel-level LMM + FDR
11. corr_hbo_velmed.ipynb           # Neural-behavioral correlations
```

## fNIRS Acquisition Parameters

| Parameter | Value |
|---|---|
| Device | NIRSport2 8-8 Core Unit (Brain Products) |
| Wavelengths | 760 nm and 850 nm |
| Raw sampling rate | 4.36 Hz |
| Analysis sampling rate | 4.00 Hz (after resampling) |
| Channels | 25 long-separation + short-separation channels |
| Chromophores | HbO, HbR, HbT, StO2 |
| Left frontal ROI | S1-D1, S2-D1, S2-D3, S1-D2, S3-D3, S4-D1, S3-D1 (7 channels) |
| Left temporal ROI | S8-D7, S8-D4, S7-D7, S7-D4, S7-D6, S6-D4, S5-D5, S5-D6, S5-D4 (9 channels) |
