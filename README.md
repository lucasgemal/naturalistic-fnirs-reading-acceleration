# Neurobiological Foundations of Reading Acceleration: A Naturalistic fNIRS Brain Imaging Study

**Status:** Manuscript in preparation

## Overview

An fNIRS study of the neural mechanisms underlying reading acceleration in 3rd- and 4th-grade
elementary school children (8–9 years old) trained with the ACELETRA® software. Longitudinal,
randomized design (10 sessions over 3 weeks), using portable fNIRS (NIRSport2) in a naturalistic
school environment.

**Main hypotheses:**
1. ACELETRA® training accelerates the automatization of the neural mechanisms of reading (lower HbO across sessions = gain in neural efficiency).
2. Training increases functional connectivity between the left temporal and frontal cortices.

## Repository Scope

This repository provides **source code only**, as used in the fNIRS data analyses of
this study (MATLAB/NIRS Toolbox and Python/statsmodels). Its purpose is
**methodological transparency**: to allow any reader to audit the processing logic,
the statistical models, and the parameters used in the research.

By the author's decision, this repository **does not include**:
- Raw, processed, or derived data (`.xlsx`, `.csv`, `.mat`, `.snirf` files)
- Numerical results or figures generated by the analyses (`.png`)
- The manuscript or its preliminary versions (`.docx`, `.pdf`)

This exclusion is **intentional** and is not due to oversight or technical limitation.
The scripts published here cannot be run end to end without the corresponding input
data, which are not made available at this time. Researchers interested in additional
methodological details, anonymized data, or collaboration may contact the author directly.

## How to Read This Repository

The scripts are organized by pipeline stage (preprocessing, statistical modeling,
neural efficiency, connectivity, channel-wise analyses). We recommend reading them
in the order below, following the header comments of each file, which document the
logic of each stage even without the input data.

```
1. contagem_nova.m            # Stimulus events/blocks
2. pre_processamento.m        # fNIRS preprocessing + first-level GLM (SubjStats)
3. MixedEffects.m             # Second-level GLM (GroupStats)
4. Contrastes.m               # Contrasts on GroupStats
5. conectividade_funcional.m  # Functional connectivity

6.  fnirs_neural_efficiency.ipynb    # Neural efficiency index
7.  lmm_neural_efficiency.ipynb      # NE LMM by ROI
8.  individual_ne_regressions.ipynb  # Individual NE slopes
9.  beta_activation_lmm.ipynb        # β activation LMM
10. connectivity_lmm_raincloud.ipynb # Connectivity LMM
11. channel_lmm_anatomical.ipynb     # Channel-wise LMM + FDR
12. corr_hbo_velmed.ipynb            # Neural × behavior correlations
13. analise_velmed.ipynb / analise_acuracia.ipynb  # Behavioral LMMs
```

## Scripts (`scripts/`)

### MATLAB — preprocessing and GLM (NIRS Toolbox)

| Script | Purpose | Expected inputs | Outputs produced |
|---|---|---|---|
| `contagem_nova.m` | Reconstructs stimulus blocks from ACELETRA triggers for each participant (calibration = 4 blocks, training = 7; 5 stimuli/block) | Raw fNIRS data + triggers | Stimulus events per session |
| `pre_processamento.m` | Resample to 4 Hz → TrimBaseline → OD → Beer-Lambert → HbT → band-pass 0.01–0.10 Hz → wavelet filter → first-level GLM (short-separation) | Raw fNIRS data with events | `SubjStats` |
| `MixedEffects.m` | Second-level GLM: `beta ~ -1 + group:experiment + (1\|subject)` (robust) | `SubjStats` | `GroupStats` |
| `conectividade_funcional.m` | Inter-channel AR-correlation connectivity (4×Fs); Fisher-z | Preprocessed data | R, Z, p, q in Excel spreadsheet |
| `relatorio_geral.m` | Quality control: number of sessions, Fs, chromophores, channels, NaN, stimuli, demographics | Preprocessed data + `SubjStats` | Console report |
| `Contrastes.m` | Second-level GLM contrasts: (1) accelerated ac_09 vs calibration, (2) non-accelerated ac_09 vs calibration, (3) group × time interaction | `GroupStats` | Per-channel t-stat figures and contrast tables (100 rows: 25 channels × 4 chromophores) |
| `block_timing_analysis.m` | Block timing statistics (onset, duration, time per stimulus, mean/SD/CV%/within-session slope) by subject × session | `hb` object (preprocessed data with stimuli) | Individual and descriptive block tables, `.mat`, and trajectory figure |
| `Hemodynamic Response Function.m` | Extracts and visualizes the HRF by ROI and group (−10 to +40 s, 4 Hz): canonical HRF, longitudinal evolution (baseline, S1, S3, S5, S7, S9), groups × ROIs panel; checks HbO/HbR coupling | `hb` object | HRF figures |
| `block_average.m` | Block average (`nirs.modules.BlockAverage`, −5 to +30 s); HbO and HbR HRF of channel S2-D3 by group | `hb` object | Canonical HRF figure |

### Python — statistical models and visualizations (Jupyter)

| Notebook | Purpose | Expected inputs | Outputs produced |
|---|---|---|---|
| `fnirs_neural_efficiency.ipynb` | NE = (−z_TimeRm − z_β) / √2, with z_β computed per ROI | Exported SubjStats + behavioral data | NE table by subject × session × ROI |
| `lmm_neural_efficiency.ipynb` | LMM: `NE ~ group × sessao_num + TimeRm_baseline + (1\|subject)`, per ROI | NE table | LMM coefficients |
| `individual_ne_regressions.ipynb` | Individual OLS of NE; Fisher exact + t-test between groups | NE table | Individual slopes |
| `beta_activation_lmm.ipynb` | LMM: `beta ~ group × sessao_num + roi + (1\|subject)` (ML) | First-level GLM β | LMM coefficients (per chromophore) |
| `connectivity_lmm_raincloud.ipynb` | LMM: `conexao_inter ~ group × session + conn_baseline + (1\|subject)`; Mann-Whitney; raincloud | Connectivity table | LMM coefficients and figures |
| `channel_lmm_anatomical.ipynb` | Channel-wise LMM with FDR (BH); 10-10 anatomical mapping | β per channel and session | Per-channel LMM table |
| `corr_hbo_velmed.ipynb` | Spearman: HbO slope × TimeRm slope for each FDR-significant channel | HbO and TimeRm slopes | Correlations |
| `ne_mannwhitney_raincloud.ipynb` | Mann-Whitney U + NE raincloud | NE table | Tests and figures |
| `ne_trajectory_plot.ipynb` | NE trajectory (mean ± SEM) by group and ROI | NE table | Figure |
| `lmm_roi_interaction.ipynb` | NE LMM with group × session × ROI interaction | NE table | LMM coefficients |
| `analise_velmed.ipynb` | Behavioral LMM of reading speed: `VELmed ~ session × grupo + (1\|SUBJID)` (REML) | `sessao_stats.xlsx` (VELmed, ms/char ≡ TimeRm) | LMM tables and group/session plot |
| `analise_acuracia.ipynb` | Behavioral LMM of accuracy (%) = ACERTOSnum / (ACERTOSnum + ERROSnum) × 100: `acuracia ~ session × grupo + (1\|subject)` (REML) | `sessao_stats.xlsx` (ACERTOSnum, ERROSnum) | LMM tables and group/session plot |
| `Calculo_eficiencia.ipynb` | Initial draft (canonical version: `fnirs_neural_efficiency.ipynb`) | — | — |

## Reference Environment

The Python scripts were developed with Python 3.12 and the statsmodels library
(v. 0.14.6). The MATLAB scripts depend on the NIRS Toolbox
(https://github.com/huppertt/NIRS-Toolbox). This information is provided as
contextual reference, not as a guarantee of execution without the original data.

## fNIRS Acquisition Parameters

| Parameter | Value |
|---|---|
| Device | NIRSport2 8-8 Core Unit (Brain Products) |
| Wavelengths | 760 and 850 nm |
| Sampling rate | 4.36 Hz (resampled to 4 Hz) |
| Chromophores | HbO, HbR, HbT, StO2 |
| Left frontal ROI | S1-D1, S2-D1, S2-D3, S1-D2, S3-D3, S4-D1, S3-D1 (7 channels) |
| Left temporal ROI | S8-D7, S8-D4, S7-D7, S7-D4, S7-D6, S6-D4, S5-D5, S5-D6, S5-D4 (9 channels) |
