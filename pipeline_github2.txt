ETAPA 2 — Converter manuscritos de DOCX para PDF
Para cada arquivo .docx em manuscript\, converta para PDF usando:
python -c "import subprocess; subprocess.run(['soffice', '--headless', '--convert-to', 'pdf', '--outdir', 'manuscript', 'manuscript/<arquivo>.docx'])"

Ou se LibreOffice estiver disponível via linha de comando:
soffice --headless --convert-to pdf --outdir manuscript\ manuscript\*.docx

Mantenha os .docx originais e adicione os .pdf gerados.
