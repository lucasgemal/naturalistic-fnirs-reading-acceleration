A pasta do repositório GitHub é:
ARQUIVO\github

Execute as seguintes etapas em sequência:

ETAPA 1 — Criar estrutura do repositório
Dentro de github\, crie as pastas:
- scripts\
- results\
- manuscript\

Copie os arquivos (não mova, mantenha os originais):
- De ARQUIVO\METODO\scripts\
  todos os .ipynb e .m → github\scripts\
  
- De ARQUIVO\RESULTADOS\
  todos os .xlsx e .png → github\results\
  
- De ARQUIVO\METODO\
  todos os .docx → github\manuscript\

ETAPA 2 — Limpar outputs dos notebooks
Para cada .ipynb copiado em github\scripts\, remova os outputs:
jupyter nbconvert --clear-output --inplace github\scripts\*.ipynb

ETAPA 3 — Criar .gitignore
Na pasta github\, crie .gitignore ignorando:
- __pycache__, .ipynb_checkpoints, *.pyc
- .DS_Store, Thumbs.db
- *.mat, *.snirf, *.nirs, *.csv, *.dat
- Pastas: input*, output*, data*, export*

ETAPA 4 — Adicionar comentários em inglês nos scripts
Para cada arquivo em github\scripts\, adicione comentários 
em inglês acadêmico:
- Docstring no início: objetivo, inputs, outputs, autor (Lucas Gemal)
- Comentários nos blocos principais explicando o que fazem
- Comentários inline nos parâmetros metodológicos importantes
- Inclua referência bibliográfica nos scripts que implementam 
  métodos específicos (ex: Neural Efficiency → Curtin & Ayaz, 2019)
- Não modifique nenhuma linha de código

ETAPA 5 — Criar README.md
Na pasta github\, crie README.md em inglês com:
- Título: Neurobiological Foundations of Reading Acceleration: 
  A Naturalistic fNIRS Brain Imaging Study
- Resumo do pipeline (fNIRS, LMM, Neural Efficiency, Connectivity)
- Estrutura do repositório (scripts\, results\, manuscript\)
- Dependências (Python 3.12, statsmodels 0.14.6, MATLAB, 
  NIRS Toolbox, MNE-NIRS)
- Como reproduzir as análises (ordem dos scripts)
- Autor: Lucas Gemal
- Status: manuscript in preparation

ETAPA 6 — Inicializar Git e criar repositório no GitHub
Execute dentro de github\:
git init
git add .
git commit -m "feat: initial commit — fNIRS reading acceleration pipeline"
gh repo create fnirs-reading-acceleration --private --source=. --remote=origin --push

Confirme cada etapa antes de avançar.
